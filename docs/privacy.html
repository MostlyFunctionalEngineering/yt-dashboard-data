Privacy Policy

YT Dashboard Data · Last updated September 23, 2026

YT Dashboard Data is a personal tool used only by its owner to view analytics for their own YouTube channel, Mostly Functional Engineering. It is not offered to the public and does not collect data from any other users.

Data the app accesses

With the owner's authorization, the app uses Google OAuth to read YouTube Analytics data for the owner's own channel through the read-only scope yt-analytics.readonly. This includes:

  • Views, watch time, average view percentage, likes, comments, and shares
  • Subscribers gained and lost
  • Per-video performance for the channel's top videos

The app also reads publicly available channel and video information (such as the channel title, subscriber count, and video titles) from the YouTube Data API.

How the data is used

The data is used for one purpose: calculating summary figures and trends (for example, week-over-week and 4-week vs. 12-week comparisons) that power a personal dashboard. It is not used for advertising, profiling, or any other purpose.

How the data is stored

  • Aggregated results are written to a JSON file in the project's public GitHub repository. The file contains channel-level statistics only and no personal information about viewers or subscribers.
  • Earlier versions of that file remain in the repository's version history.
  • The OAuth credentials the app uses to access Google are stored as encrypted GitHub Actions secrets and are never published.

Sharing

The app does not sell, rent, or transfer Google user data to third parties. The only place results are published is the repository described above.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke the app's access at any time at myaccount.google.com/permissions. Revoking access stops all further data collection. The stored JSON file can be deleted from the repository at any time.

Changes to this policy

If the way the app handles data changes, this page will be updated and the date above will change.
