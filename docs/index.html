YT Dashboard Data

A personal tool that collects analytics for the Mostly Functional Engineering YouTube channel and turns them into a dashboard.

What it does

YT Dashboard Data runs on a schedule, reads the owner's own YouTube channel analytics (views, watch time, subscriber changes, engagement, and top videos), and writes summary figures to a JSON file. The dashboard reads that file to show weekly and monthly trends.

Who uses it

Only the channel owner. The app is not offered to the public, has no sign-in for other people, and does not collect data from anyone else.

Google user data

The app requests read-only access to YouTube Analytics for the owner's channel. Details on how that data is used and stored are in the privacy policy.
